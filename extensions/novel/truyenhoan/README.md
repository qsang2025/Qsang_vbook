# Extension Truyện Hoàn (vBook)

Extension đọc truyện chữ tiếng Việt miễn phí từ **Truyện Hoàn** (`https://truyenhoan.com`), có hỗ trợ mirror sang **WeTruyen** / **DTruyen** (`https://wetruyen.com`).

## Tính năng
- Đầy đủ thể loại: Tiên Hiệp, Kiếm Hiệp, Huyền Huyễn, Đô Thị, Võng Du, Khoa Huyễn, Dị Giới...
- Danh mục: Truyện Hot, Mới Cập Nhật, Đã Hoàn Thành, Truyện Mới Đăng.
- Hỗ trợ phân trang danh sách truyện và phân trang mục lục chương (`page.js` + `toc.js`).
- Đọc toàn văn chương đầy đủ (`#chapter-c`), loại bỏ quảng cáo và script.
- Tùy chọn chuyển đổi domain qua mục cài đặt plugin (`truyenhoan.com` / `wetruyen.com` / `dtruyen.com`).
