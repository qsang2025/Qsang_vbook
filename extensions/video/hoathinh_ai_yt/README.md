# Hoạt Hình AI YouTube

Extension vBook xem **Hoạt Hình AI Trung Quốc / Donghua 3D** trên YouTube (`https://www.youtube.com`), tập trung vào:

- **Bộ AI Dài Tập (Playlist)**: tự động phân trang `continuation` lấy toàn bộ tập, bỏ qua video Private/Deleted/Shorts (< 120s), tự động chuẩn hóa thứ tự `Tập 1 -> Tập N`.
- **Bản Full Nhiều Tiếng**: lọc bỏ Shorts và video ngắn (`< 1200s` / < 20 phút).
- **Kênh Tuyển Chọn**: CibiiSub, Zzzphim, Não Phẳng Tu Tiên, 2K Sub, Giấc Mộng Tu Tiên, Pi Studio.
- **Phát Native HLS / MP4**: 3-tier stream resolver (YouTube InnerTube `ANDROID_VR`/`IOS` -> Piped -> Invidious) kèm track `Re-resolve`.
