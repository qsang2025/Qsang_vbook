1. Bản chất và nguyên nhân gốc rễ gây ra lỗi HTTP 504 Gateway Timeout / 502 Bad Gateway trên các extension Sáng Tác Việt khi đọc trên thiết bị di động.

5. Đề xuất các giải pháp kỹ thuật cụ thể (Smart Retry sau 3-5s sang mirror kế tiếp, host-based cooldown, cải tiến thông báo lỗi) cho `SangtacvietApp` v4 và `Sáng Tác Việt` v9.

- Nhánh `research/stv-504-kychi` đã được tạo từ `origin/fix/stv-p1p2`.
- Hai extension nội bộ:
  - `extensions/novel/sangtacviet` (v9): Web scraping, WebView JS grant.
  - `extensions/novel/sangtacvietapp` (v4): API `/mobile/bookinfo.php`, Smart Key Caching.
  - Cả hai đang áp dụng quy tắc I3 (dừng thử mirror khi có response 4xx/5xx) và I4 (pacedFetch jitter 0.5-1.5s, cooldown 60m khi 405/429).
- Extension kychi (`extensions/chinese_novel/sangtacviet-app` trong `vbook-ext_kychitoge`):
  - Mã hóa `encrypt: true`.
  - Cấu hình `delay: 30000`, `thread_num: 1`, `LICENSE_KEY`, `CONFIG_URL`.
  - Bị lỗi "Lỗi parse dữ liệu từ License Server" do kết nối tới server xác thực bản quyền cá nhân bên thứ ba bị sập/lỗi phản hồi.
- 4 domain STV:
  - `.app`, `.vip` qua Cloudflare CDN (Edge Singapore).
  - `.com`, `.pro` trỏ thẳng tới IP gốc `103.82.20.93` (Nginx 1.18.0 trên Ubuntu tại CloudFly VNPT Hanoi).
  - Tất cả chung 1 backend PHP-FPM duy nhất.
